# Security and privacy

Please report suspected vulnerabilities through GitHub's private
vulnerability reporting when enabled, or contact the maintainer through an
appropriate private channel. Do not open a public issue containing a token,
credential, personal data, or exploit details.

OAuth tokens and Desktop client secrets are sensitive credentials. Store them
outside the repository with restrictive permissions. Transcripts and chats
may contain personal data; apply appropriate access, retention, and deletion
policies.

The currently supported development line is 0.1.x on `main`. This project
makes no claim that participation evidence is attendance, grading, assessment,
or a dropout diagnosis.
